「API 路由」页负责 llama-server 服务的启动、停止与实时监控。服务启动后提供一个 **OpenAI 兼容**的接口，任何支持该协议的客户端都能直连。

## 启动与停止

- **启动服务**：扫描模型目录并按每个模型的参数生成预设，然后启动 llama-server。模型目录为空（找不到任何 GGUF 文件）时会启动失败并提示，请先下载模型；
- **停止服务**：结束 llama-server 进程，释放显存与内存；
- **重启**：修改模型参数或服务配置后，用重启让新设置生效。

状态灯旁显示服务地址（默认 `http://127.0.0.1:8080`）和运行时长。下方「可用模型」列出模型目录里识别到的模型。

## 服务参数

点齿轮图标展开参数面板：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| Port | 8080 | 服务监听端口，范围 1024–65535 |
| 最大并发模型 | 1 | 同时加载在显存/内存中的模型数量 |
| Prompt 缓存 (MiB) | 8192 | 系统内存中预留的 prompt 缓存大小 |

服务运行中参数面板会被锁定（显示「停止后可修改」），避免运行时改配置导致不一致。

## 监控指标

页面下方实时刷新（每秒一次）：

- **服务日志**：llama-server 的原始输出，排查问题的第一现场；
- **系统监控**：CPU、内存占用和每块 NVIDIA 显卡的使用率与显存占用；
- **Token 速度**：提示词处理速度（prefill，处理你输入内容的速度）与生成速度（decode，模型吐字的速度），思考与回答都属于解码过程。

## 用代码调用服务

服务完全兼容 OpenAI Chat Completions 协议，例如用 curl：

```bash
curl http://127.0.0.1:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d "{
    \"model\": \"模型名\",
    \"messages\": [
      { \"role\": \"user\", \"content\": \"你好，介绍一下你自己\" }
    ]
  }"
```

第三方客户端（如各类聊天前端、IDE 插件）中把 API Base URL 填成 `http://127.0.0.1:8080/v1`、API Key 随意填即可（未设置认证时）。

## 局域网访问与 API Key

这两项在「偏好设置」页配置，修改后在下一次启动服务时生效：

- **服务访问范围**：`本地（127.0.0.1）` 只有本机能访问；`局域网（0.0.0.0）` 允许同一网络里的其他设备访问，此时服务地址用本机的局域网 IP；
- **API Key**：设置后，调用推理接口必须携带该 Bearer Token：

```bash
curl http://127.0.0.1:8080/v1/chat/completions \
  -H "Authorization: Bearer 你的APIKey" \
  -H "Content-Type: application/json" \
  -d "{ \"messages\": [ { \"role\": \"user\", \"content\": \"你好\" } ] }"
```

把服务开放到局域网时，强烈建议同时设置 API Key。
