三步就能把本地大模型跑起来：**装运行时 → 下模型 → 启动服务**。每一步只需点一两个按钮，全程不需要命令行。

## 第一步：安装 llama.cpp 运行时

llama.cpp 是真正执行推理的引擎，应用通过它启动本地服务。

1. 打开左侧「运行环境」页。
2. 如果显示「未找到」，点击「下载 llama.cpp」，应用会自动获取最新版本并解压到下载路径。
3. 下载完成后，状态会变为「已安装」，并显示版本号和安装路径。

如果你已经自己下载过 llama.cpp（目录里能找到 llama-server 主程序），也可以点「自定义」直接选择那个目录，无需重复下载。

## 第二步：下载模型

模型是 `.gguf` 格式的权重文件，从「模型下载」页获取：

1. 打开「模型下载」页，在搜索框输入模型名（如 `Qwen`、`DeepSeek`）。
2. 在搜索结果中点击感兴趣的模型，进入详情页。
3. 勾选需要的 `.gguf` 文件（不确定就选体积适中的 Q4 量化版本），点击「下载选中文件」。
4. 下载进度显示在右下角任务卡和下载管理面板中，支持暂停、继续与断点续传。

下载完成的模型会自动出现在「模型管理」页。国内网络推荐先在设置页把下载源切换为 HF 镜像或 ModelScope，速度更稳定。

## 第三步：启动服务

1. 打开「API 路由」页，点击「启动服务」。
2. 状态变为「运行中」后，服务地址显示在页面上（默认 `http://127.0.0.1:8080`）。
3. 现在你可以：
   - 在「本地聊天」页直接与模型对话；
   - 用任何 OpenAI 兼容的客户端连接这个服务（见「API 服务」章节的示例）。

## 首页的快速上手引导卡

第一次使用时，「系统信息」页顶部会显示一张「快速上手」清单卡：

- 卡上列出上面这三步，未完成的步骤带「去设置」按钮，点击直接跳到对应页面；
- 每完成一步会自动打勾；全部完成后卡片自动隐藏；
- 点「不再显示」可以随时收起这张卡，之后不再出现。

侧边栏底部还有一个系统状态点： llama.cpp 已安装且模型目录里至少有一个模型时，显示绿色「系统就绪」。
